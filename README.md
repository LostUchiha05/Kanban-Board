# 📋 Interactive Kanban Board

A clean, responsive, and feature-rich Kanban Board web application designed for task management and workflow visualization. Built entirely with vanilla **HTML5**, **CSS3**, and **JavaScript** (no external frameworks).

## ✨ Features

- **Dynamic Board Creation:** Add new custom columns/boards instantly with automated unique IDs.
- **Horizontal Drag & Drop:** Seamlessly reorder boards across the workspace using the HTML5 Drag and Drop API.
- **Smart Auto-Scrolling:** Automatically scrolls the workspace horizontally when dragging boards near the edges.
- **Dynamic Layout Controls:** Adjust column spacing in real-time using an interactive range slider.
- **Modern UI/UX:** Styled with custom gradients, smooth transitions, font icons, and responsive layouts.

## 🛠️ Built With

- **HTML5** (Semantic structure & Drag/Drop API)
- **CSS3** (Flexbox, CSS Variables, Gradients, Custom Scrollbars)
- **JavaScript (ES6+)** (DOM Manipulation, Event Listeners, Bounding Client Rect calculations)
- **FontAwesome** (UI icons)
